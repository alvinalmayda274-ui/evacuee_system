# Evacuee System - Evacuation Center Management

A web-based Evacuee Management System for barangays and evacuation centers.
It helps staff record evacuees faster, track families per evacuation center, and monitor relief distribution in real-time during disasters.

## Problem Solved
During calamities, evacuee lists are written manually on paper, causing duplicate records, slow counting, and delayed relief distribution. This system makes registration digital and organized.

## Features
- Evacuee Registration - Add, Edit, Delete Evacuee Profile
- Family Profiling - Group members by household / family head
- Evacuation Center Management - Assign evacuees per center / room
- Search & Filter - Search by name, barangay, or evacuation center
- Dashboard - Total evacuees, families, and per-center count
- Relief Distribution Tracking - Record who received relief goods
- Reports - Printable list of evacuees per center

## Tech Stack
- PHP, MySQL, HTML, CSS, JavaScript, Bootstrap
- XAMPP / phpMyAdmin

## How To Run
1. Copy folder evacuee_system to C:/xampp/htdocs/
2. Start Apache and MySQL in XAMPP
3. Open phpMyAdmin and import the database file .sql
4. Open in browser: http://localhost/evacuee_system
